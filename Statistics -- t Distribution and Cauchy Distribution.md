Z-score for a Standard Normal Distribution:
$$Z=\frac{\bar X -\mu}{\sigma/\sqrt{n}}$$
But for a small sample, Gosset didn't the the population $\sigma$, he had to use the **sample standard deviation (s)**. He replaced $\sigma$ with $s$ to create a new variable, $t$:
$$t=\frac{\bar X -\mu}{s/\sqrt{n}}$$
Multiplying both numerator and denominator by $1/\sigma$:
$$t=\frac{\frac{\bar X -\mu}{\sigma/\sqrt{n}}}{s/\sigma}$$
+ Numerator: This is *standard normal variable (Z)*.
+ Denominator: This is related $\chi^2$ distribution

>[!Note]
>Definition of sample variance, $s^2$:
>$$s^2=\frac{\sum{(x_i-\bar x)^2}}{n-1}$$
>
